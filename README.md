# gestion_de_stades
Projet de programmation linéaire pour optimiser la gestion des flux de spectateurs dans les stades. Il résout deux problèmes d’optimisation en utilisant la méthode graphique et l’algorithme du simplexe, implémentés en Python avec numpy, matplotlib et scipy.
Optimization project for spectator flow management in stadiums during the 2030 FIFA World Cup preparation.
This project models and solves two linear programming problems using:

Graphical Method
Simplex Algorithm

The implementation is developed in Python using:

numpy
matplotlib
scipy
📌 Project Context

As part of the preparation for the 2030 FIFA World Cup hosted by Morocco, Spain, and Portugal, stadium organizers must optimize spectator entry and security management.

The objective is to maximize spectator flow while respecting several constraints such as:

Budget limits
Number of security gates
Number of security agents
Number of smart cameras
Stadium capacity
Energy consumption
🎯 Objectives
Model real-world optimization problems using Linear Programming
Solve a 2-variable optimization problem using the graphical method
Solve a 3-variable optimization problem using the simplex method
Validate results using scipy.optimize.linprog
Visualize feasible regions and optimal solutions
Automate calculations with Python
